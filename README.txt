 校园活动管理系统（Campus Activity System）

 一、项目简介

本项目是一个基于 Android + SpringBoot + MySQL 的校园活动管理系统，主要用于解决校园活动发布与报名过程中信息分散、管理不便的问题。

系统实现了活动的发布、浏览、报名、管理等功能，支持普通用户与管理员两种角色，能够在一定程度上提升活动组织效率。

登录注册、活动管理以及个人信息等功能均已实现后端支持，并通过接口与前端进行数据交互。

---

 二、功能介绍

 1. 用户功能
	- 用户注册与登录
	- 个人中心信息展示
	- 查看已报名活动并管理

 2. 活动功能
	- 活动列表展示
	- 活动搜索与筛选
	- 活动详情查看

 3. 报名功能
	- 报名活动
	- 取消报名
	- 查看“我的报名”

4. 管理员功能
	- 发布活动
	- 删除活动
	- 查看报名人员
	- 手动添加报名人员

---

 三、系统特点

1. 前后端分离  
	- 前端：Android  
   	- 后端：SpringBoot  
   	- 使用 RESTful API 进行通信  

2. 权限控制  
  	- 普通用户与管理员分离  
   	- 管理员可进行活动管理操作  

3. 数据统一管理  
  	- 所有数据存储在 MySQL  
   	- 包括用户、活动、报名信息  

4. 报名状态自动更新  
   	- 后端使用定时任务  
   	- 根据报名截止时间自动更新状态  

---

## 四、技术栈

前端（Android）
	- Java
	- RecyclerView
	- Retrofit
	- OkHttp

 后端（SpringBoot）
	- SpringBoot
	- Spring MVC
	- Spring Data JPA
	- 定时任务（@Scheduled）

 数据库
	- MySQL

 六、运行说明

1. 后端启动
	1. 配置 MySQL 数据库
	2. 导入数据表（user、activity、apply）
	3. 启动 SpringBoot 项目

---

 2. 前端运行
	1. 使用 Android Studio 打开 android 项目
	2. 修改接口地址为后端服务器 IP
	3. 运行项目

---

七、典型使用流程

	1. 用户登录系统  
	2. 浏览活动列表或进行搜索  
	3. 点击活动查看详情并报名  
	4. 在“我的报名”中查看或取消报名  
	5. 管理员可发布活动并管理报名人员
