 校园活动管理系统（Campus Activity System）

 一、项目简介

本项目是一个基于 Android + SpringBoot + MySQL 的校园活动管理系统，主要用于解决校园活动发布与报名过程中信息分散、管理不便的问题。

系统实现了活动的发布、浏览、报名、管理等功能，支持普通用户与管理员两种角色，能够在一定程度上提升活动组织效率。

登录注册、活动管理以及个人信息等功能均已实现后端支持，并通过接口与前端进行数据交互。

---

 二、功能介绍

1. 用户模块
	- 用户注册
	- 用户登录
	- 个人中心信息展示
	- 区分普通用户与管理员权限

 2. 活动模块
	- 活动列表展示
	- 活动搜索与筛选
	- 活动详情查看
	- 活动状态展示（实时更新）
	- 实时统计活动报名人数

 3. 报名功能
	- 报名活动
	- 取消报名
	- 查看“我的报名”

4. 管理员功能
	- 发布活动
	- 删除活动
	- 查看报名人员
	- 手动添加或删除报名人员

5. 状态管理
	- 根据报名截止时间自动更新活动报名状态
	- 在活动列表中显示“报名中”“报名截止”等状态信息
---

 三、系统特点

1. 前后端分离  
	- 前端：Android + Java
   	- 后端：SpringBoot  

2. 权限控制  
  	- 普通用户与管理员权限分离  
   	- 管理员可进行活动管理操作  

3. 数据统一管理  
  	- 所有数据存储在 MySQL  

4. 报名状态自动更新  
   	- 后端使用定时任务  
   	- 根据报名截止时间自动更新状态

 五、运行说明

1. 后端启动
	1. 配置 MySQL 数据库
	2. 导入数据表（user、activity、apply）
	3. 启动 SpringBoot 项目
	
---

 2. 前端运行
	1. 使用 Android Studio 打开 android 项目
	2. 修改接口地址为后端服务器 IP
	3. 运行项目
